# O que é Python e para que serve

Python é uma linguagem de programação criada em 1989 por Guido van Rossum. O nome vem de uma série de comédia britânica, não da cobra! Desde então, virou uma das linguagens mais usadas no mundo.

## Por que Python?

Python foi projetada com um objetivo claro: **código legível**. A sintaxe é simples e se parece com o português. Isso facilita aprender, manter o código e trabalhar em equipe.

```python
# Compare com linguagens mais complexas:
# Java: System.out.println("Olá");
# C: printf("Olá\n");
# Python:
print("Olá")
```

Vê só? Python é direto. Você escreve o que pensa.

## Onde Python é usado?

### 🌐 Web
Sites e APIs com **Django** e **Flask**. Plataformas como Instagram, Spotify, Pinterest usam Python no backend.

### 📊 Dados e análise
**Pandas**, **NumPy**, **Matplotlib**. Cientistas de dados e analistas usam Python para processar e visualizar informações.

### 🤖 Inteligência Artificial
**TensorFlow**, **PyTorch**, **Scikit-learn**. A maioria dos modelos de IA são treináveis em Python.

### ⚙️ Automação
Scripts que automatizam tarefas repetitivas. Desde renomear arquivos em massa até fazer web scraping.

### 🎮 Jogos
**Pygame** permite criar jogos 2D. Protótipos e projetos educacionais usam muito.

### 🔬 Ciência
Physics simulations, bioinformática, astronomia. Python está em quase todo laboratório.

## Como funciona: Interpretado vs Compilado

Python é uma **linguagem interpretada**. Isso significa que o código é lido e executado linha por linha, sem precisar ser compilado em linguagem de máquina antes.

<Callout tipo="dica">
**Linguagem compilada** (como C): você escreve → compila → gera um executável → executa.

**Linguagem interpretada** (como Python): você escreve → executa direto.
</Callout>

Vantagem: mais rápido de testar ideias.
Desvantagem: pode ser mais lento em operações pesadas.

## O ciclo de vida do código Python

1. Você escreve um arquivo `.py`
2. Python passa por um **parser** que verifica a sintaxe
3. Converte em **bytecode** (representação intermediária)
4. A **máquina virtual Python (PVM)** executa o bytecode
5. Resultado aparece na tela

Tudo isso acontece instantaneamente quando você roda `python seu_arquivo.py`.

## Resumo

- Python é simples, legível e versátil
- Usado em web, dados, IA, automação e jogos
- É interpretada: executa direto, sem compilação
- Domina a ciência de dados e IA
